Aardwolf MUSHclient Package Trust FAQ

What code is running inside the Aardwolf MUSHclient Package?
All parts of the Aardwolf MUSHclient Package are free/open-source software, which means that you can freely read and modify the underlying source code for yourself.
The installer itself is generated automatically using NSIS scripts available at https://github.com/fiendish/aardwolfclientpackage-installer and also uploaded to GitHub using a continuous integration service called AppVeyor according to the instructions found in the project's appveyor.yml configuration file at https://github.com/fiendish/aardwolfclientpackage/blob/MUSHclient/appveyor.yml.
The download site at https://fiendish.github.io/aardwolfclientpackage is also automatically updated with new download links at the same time using the HTML template files at https://github.com/fiendish/aardwolfclientpackage/tree/gh-pages.
MUSHclient.exe is compiled directly from the source code found in https://github.com/fiendish/mushclient by the GitHub build system using the configuration at https://github.com/fiendish/mushclient/blob/master/.github/workflows/latest-dev-build.yml.
The Aardwolf MUSHclient Package also includes directly-from-source-code builds of LuaJIT, Lua-openssl, Lua-llthreads2, and LuaSocket, each of which can also be found on GitHub at https://github.com/fiendish/LuaJIT, https://github.com/fiendish/lua-openssl, https://github.com/fiendish/lua-llthreads2, and https://github.com/fiendish/luasocket and which are all also built automatically through GitHub with https://github.com/fiendish/LuaJIT-build, https://github.com/fiendish/lua-openssl-build, https://github.com/fiendish/lua-llthreads2-build, and https://github.com/fiendish/luasocket-build respectively.
From the moment a set of changes enters the main MUSHclient code branch at https://github.com/fiendish/aardwolfclientpackage, the installer is automatically bundled in a clean virtual environment and then immediately uploaded without any interaction from me or my computer.
How can I trust you?
You don't need to. That's intentional. I don't want you to need to trust me to trust my software. At most you need to be able to trust your own eyes and the automated systems at AppVeyor and GitHub, both of which are major companies with reputations for safety and security and trustworthiness to maintain.
How can I trust that AppVeyor and GitHub aren't secretly injecting viruses into the compiled package?
I don't know how to answer that for you. I trust their reputations, and I trust what they have to lose financially if they ever do anything like that. If you don't trust them, you can visit https://www.appveyor.com and https://www.github.com to learn more about them.
Microsoft/Symantec/AVG/McAfee/etc says that your installer is suspicious because you didn't sign it.
If you don't know what Code Signing is, you may want to read https://web.archive.org/web/20190613090321/https://blogs.msdn.microsoft.com/ieinternals/2011/03/22/everything-you-need-to-know-about-authenticode-code-signing/. Code signing certificates aren't free. In fact, they're very expensive for a project that I make no money doing. Code signing certificates are a great idea if you're a company who gets to charge hundreds of dollars per year for the right to say that I am who I say I am. Code signing doesn't seem so great from my perspective, because I don't want to have to pay hundreds of dollars per year to a cartel engaging in a protection racket. Unsigned code warnings are nothing more than them saying to me, "Gosh, it sure would be a shame if we scared away potential users (wink wink)." If the certificates were based on inspection of the actual source code and building the installer inside their special trusted environment, that would be one thing, but that isn't how they get assigned. Certificates are assigned based on whether or not I want to give the trust cartel a lot of money. If anyone feels like they want to donate the money for paying off the cartel for a few years, then I'll graciously look into signing the software.
Microsoft/Symantec/AVG/McAfee/etc says that your installer is or contains a virus.
